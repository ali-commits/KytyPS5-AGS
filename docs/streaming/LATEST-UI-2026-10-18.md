# Current upstream launcher with streaming and experimental audio

The launcher follows the UI in `KytyPS5/KytyPS5` at
`fe3857a1715551e4f554b2ec29cc1ca3286287a1`.

The library has upstream's shared grid/list views, cover-size slider, search,
selection, sorting and context actions. The installed profile opens in icon view;
the grid button beside search switches back to the list. Both views use the same
games and selection. The source retains upstream's default for new profiles.

The settings retain every upstream widget, including trophy duration and the
Rendering compatibility group. They also retain our five experimental audio
volumes, 3D-object switch and accurate occlusion control. The Streaming tab,
phone-owned stream preferences, controller-audio setup, cheat safeguards and shared
local/streamed launch arguments remain connected.

Controller setup uses upstream's shared preview. Title audio is canceled during
local games, hosting and streaming-tab use, including headless startup. Official
self-updates remain unavailable to custom builds, as in upstream's policy.

Linux deployment keeps bundled Qt plugins and exposes the installed desktop's
matching theme/style plugins using Qt's multiple-plugin-path support. The launcher
follows the desktop theme rather than forcing a style; on this KDE installation,
the native style is Breeze. The current library form, icons and stylesheet match
the pinned upstream source. The new `kyty_launcher` executable and the compatible
`launcher` entry point are both supplied.

The package is installed at
`~/.local/opt/kytyps5-streaming/20261018-upstream-ui`, with a matching private
configuration directory. `kytyps5-streaming` opens it. The matching Phone + TV host
uses `kyty-three-apps-20261018-ui.service`.

The previous installation supplies an independent copy of its current saves and
settings, together with the complete streaming identity and all pairings. Signed
phone/TV applications are unchanged. The previous package and command/desktop
backups remain available for rollback. Stop the new host before restoring the old
host; saves do not automatically copy backward.

Verification and UI images are under `verification/latest-ui` in the package;
`installation-provenance.json` records the exact native, launcher and backend hashes.
